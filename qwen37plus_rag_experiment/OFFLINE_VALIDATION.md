# 离线检索预检结果

本预检使用用户上传的以下文件完成：

- `sku_kb_cleaned.xlsx`：2020行，其中2019行具有有效`sku_id`并进入索引；
- `instances_gt_v1_enriched.xlsx`：653个裁剪实例，其中340个实例具有真值SKU；
- Direct基线的`input_manifest.csv`和`direct_predictions.csv`。

预检只运行知识库检索，不调用Qwen API，不代表最终RAG识别性能。

## Top-K候选召回率

| 指标 | 结果 |
|---|---:|
| Top-1召回率 | 60.88%（207/340） |
| Top-3召回率 | 78.53%（267/340） |
| Top-5召回率 | 86.18%（293/340） |
| Top-10召回率 | 90.29%（307/340） |
| Top-20召回率 | 91.47%（311/340） |

默认正式实验采用Top-5，原因是候选上下文较短、模型比较负担较低，并且已覆盖大部分具有真值SKU的样本。Top-10可作为后续检索参数消融。

## 结果解释

- Direct已经输出`matched`的SKU真值样本中，Top-5召回明显高于Direct输出`unknown`的样本。
- 当第一阶段没有提取到有效名称、厂家、规格或条码，纯文本知识库检索缺少可靠查询线索，候选召回会下降。
- 同名中药饮片存在多个厂家、规格或商品编码时，仅凭通用名称难以确定唯一SKU，因此Top-1低于Top-5。
- 最终RAG的严格SKU准确率不会自动等于Top-5召回率，还取决于Qwen能否依据图片从候选中选择正确SKU。

## 实验设计注意

当前RAG流程复用冻结的Direct结果进行检索，再执行一次“图片+候选”复核。与单次Direct基线相比，RAG系统同时增加了知识库候选和第二次模型复核。若论文需要严格分离知识库贡献，建议后续增加“图片+冻结Direct结果+第二次复核，但不提供知识库候选”的两阶段无知识库对照组。
